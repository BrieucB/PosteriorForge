V3 same-pair original physical assessment; Built with PriorLabs-TabPFN. The
original50000-row/21marginal/32joint/CDF/mean/SD/reference gates are
unchanged. Only complete v3 physical parents and one separately authenticated
physical G3 are eligible. No model, GPU, new posterior or reference
integration runs here. NEW G3 validation uses its actual saved Z; OLD baseline
custody replays its already-recorded private stream, without another
posterior/G3.
