# Native routing v2: focused CPU tests

Built with PriorLabs-TabPFN.

The v2 route is original all-eight FP32 at ordered stages 6, 10 and 14; other
18 stages delegate to frozen88. These tests cover reverse-checked route/label
AST deltas, exact unchanged numerical helper identities, native14 no-prefill
and cleanup semantics, exported/base/private callable/config tamper rejection,
private922 local backend imports, validator/witness tuple and count metadata,
original550's retained (6,10) ancestry and fbed's failure-selection-only scope.
V1 sources/globals remain unchanged. Both actual lineage labels and altered
selection/CPU/pair/shape custody are checked before numerical validation.

Positive CPU-binding replay stubs the numerical validator explicitly. No test
claims a fresh neural comparison or a v2 numerical/posterior pass. Model calls,
worlds, posterior draws, reference integrations, GPU submissions and ledger
changes are absent. Exact logs, versions and before/after hashes are retained.
The fixed actual pair data comes from the closed CPU6f35 receipt; all v1 proofs
are rejected as v2 activation evidence. Whitespace was checked before this run.
