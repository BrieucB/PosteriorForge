# Pair qualifier CPU guard tests

Built with PriorLabs-TabPFN.

These are focused CPU binding/config/reference/source/seed-clone guards, not a
neural numerical screen. Exact raw logs and before/after source hashes are
recorded in receipt.json. Both locked environments test the immutable23-pair
scope, actual original case2 reference metadata, altered pair/custody/masks,
missing/changed pins and FIRST-only GPU authorization. The positive CPU receipt
binding test explicitly stubs its numerical validator and makes no NN pass
claim. No model calls, worlds, posterior draws, reference integrations, GPU
submission or ledger changes occur. Actual all23 CPU inventories and their
case2 regression have a separate closed receipt6f35. No arrays are included.
